# Учёт показаний счётчиков

Программа для учёта показаний различных счётчиков (электроэнергия, вода, газ и т.д.) с графическим интерфейсом и поддержкой файлов команд.

## Возможности

- Графический интерфейс на Tkinter
- Добавление новых показаний
- Удаление выбранных записей
- Загрузка данных из файла
- Выполнение команд из файла (ADD, REM, SAVE)
- Поиск по ресурсу и дате
- Логирование ошибок
- Модульное тестирование

## Формат данных

Каждая запись содержит:
- **Ресурс** - название ресурса (строка)
- **Дата** - в формате `ГГГГ.ММ.ДД` или `ГГГГ-ММ-ДД`
- **Значение** - показание счётчика (число)
- **Качество** - строка (good, normal, bad, excellent и т.д.)

### Пример строки в файле:
```
"Электроэнергия" 2024.11.20 150.75 good
"Водоснабжение" 2024.12.01 95.00 normal
```

## Команды

Программа поддерживает выполнение команд из текстового файла:

### ADD - добавление показания
```
ADD ресурс; дата; значение; качество
```
Пример:
```
ADD Электроэнергия; 2024.11.20; 150.75; good
```

### REM - удаление по условию
```
REM поле оператор значение
```
**Поля:** resource, date, value, quality

**Операторы:** =, !=, <, >, <=, >=

Примеры:
```
REM value < 100
REM quality = bad
REM resource = Отопление
```

### SAVE - сохранение в файл
```
SAVE путь/к/файлу.txt
```

## Установка и запуск

### Требования
- Python 3.10 или выше
- Установленные зависимости (только стандартная библиотека)

### Запуск программы
```bash
python main.py
```

### Запуск тестов
```bash
# Установка pytest (если не установлен)
pip install pytest pytest-cov

# Запуск всех тестов
python -m pytest tests/ -v

# С оценкой покрытия
python -m pytest tests/ -v --cov=. --cov-report=term
```

## Пример файла команд

Создайте `commands.txt`:

```txt
# Добавление показаний
ADD Электроэнергия; 2024.11.20; 150.75; good
ADD Водоснабжение; 2024.12.01; 95.00; normal

# Удаление показаний со значением меньше 100
REM value < 100

# Сохранение результата
SAFE result.txt
```
